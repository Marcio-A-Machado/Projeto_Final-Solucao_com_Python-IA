# 📊 Projeto de Análise de Vendas com Python

Este projeto simples faz uma análise exploratória de dados de vendas usando **Python**, **Pandas** e **Matplotlib**.

## 🚀 Objetivo
Demonstrar conhecimentos básicos de:
- Leitura e manipulação de dados
- Estatísticas descritivas
- Visualização de dados
- Geração de insights simples

## 🧠 Tecnologias usadas
- Python 3
- Pandas
- Matplotlib

## 📈 Resultados
O script mostra:
- Média das vendas
- Gráfico de vendas mensais
- Um insight automático sobre o desempenho final do ano
